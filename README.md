# ClipGenius AI — Starter

واجهة أولية متجاوبة بالعربية، مع اختيار مصدر الفيديو، التحقق من شكل الرابط، واختيار لغة الترجمة.

## التشغيل
افتح `index.html` في المتصفح، أو ارفع الملفات إلى GitHub Pages.

## الحالة الحالية
هذه **واجهة Frontend أولية فقط**. لم يتم تنفيذ تنزيل الفيديو أو تحليل الصوت/الصورة أو إنشاء المقاطع أو تسجيل الدخول أو الاشتراكات. زر التحليل لا يشغّل معالجة وهمية.

## المرحلة التالية
1. إعداد Backend API.
2. رفع ملفات يملك المستخدم حق معالجتها إلى تخزين خاص.
3. تفريغ الصوت إلى نص وتحديد المقاطع المرشحة.
4. القص والترجمة وإعادة التأطير عبر FFmpeg.
5. إضافة تسجيل الدخول وقاعدة البيانات والاشتراكات.

## حقوق المحتوى
استخدم واجهات المنصات الرسمية أو ملفات تملكها أو لديك تصريح بمعالجتها. لا تتجاوز DRM أو صلاحيات الوصول.
